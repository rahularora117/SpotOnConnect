# SpotOnConnect

Meet People Around You

SpotOnConnect is a location-based social networking app that helps people discover nearby users, activities, communities, and events in real time.

## Features

- 🗺️ Live Radar Map
- 👥 Nearby People
- 🎉 Activities
- 🏘️ Communities
- 💬 Real-time Chat
- 📍 GPS Location
- 🔒 Secure Authentication with Supabase
